# Raju 3D Developer Portfolio

A dark cinematic portfolio built with React, Three.js / React Three Fiber and GSAP.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

## Personal assets

- `public/profile.jpg` — replace with your preferred professional photo.
- `public/resume.pdf` — replace with your updated resume when ready.

## Important

The contact form is intentionally UI-only. Connect it to Formspree, EmailJS or your own backend before using it for real messages.

Project information is centralized in `src/data/portfolio.js`, so future updates are easy.
